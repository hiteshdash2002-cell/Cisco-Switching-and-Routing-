# Cisco Networking Basics
## IP Addressing
* IPv4 Address: 32-bit logical address.
* IPv6 Address: 128-bit hexadecimal address.

## Core Protocols
* TCP (Transmission Control Protocol): Connection-oriented and reliable.
* UDP (User Datagram Protocol): Connectionless and fast.

## Networking Devices
* *Routers:* Layer 3 devices used to connect different networks.
* *Switches:* Layer 2 devices used to connect devices within the same network.
